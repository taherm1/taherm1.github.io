# Taher's Redirect Site

A polished, professional redirect page for my personal resume.

## Features
- **Polished UI:** Modern dark theme with animated mesh gradients and glassmorphism.
- **Progress Tracking:** Visual circular progress ring for the redirect countdown.
- **Quick Actions:** Buttons to skip the wait or cancel the redirect.
- **Social Integration:** Linked to my professional LinkedIn profile.

## Tech Stack
- Pure HTML/CSS/JS (no external dependencies)
- Responsive design for all devices
- SEO optimized
